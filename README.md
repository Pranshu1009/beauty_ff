# Roshani Chaurasiya — Celebrity Makeup Artist

Luxury pink-themed React website for celebrity makeup artist **Roshani Chaurasiya**.

## Pages

- Home (full landing with all sections)
- About
- Portfolio
- Services
- TV Work
- Academy
- Testimonials
- Contact

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Stack

- React + Vite
- React Router
- Custom CSS with pink luxury gradients
